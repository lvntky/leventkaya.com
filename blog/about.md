I'm Levent Kaya, a computer science graduate student and systems programmer based in Istanbul.

This blog documents my work in low-level programming — the kind where you care what the hardware is actually doing. I write about C and C++, operating system internals, graphics programming without abstractions, debugger internals, and retrocomputing.

## Projects

- **[fbgl](https://github.com/lvntky/fbgl)** — A zero-dependency Linux framebuffer graphics library written in C. Direct `/dev/fb0` access, no SDL, no OpenGL.
- **[BoltDbg](https://github.com/lvntky/boltdbg)** — A cross-platform debugger built on `ptrace(2)`. Modern debugger internals from scratch in C++.
- **[c6502](https://github.com/lvntky/c6502)** — A MOS 6502 emulator and integrated debugging suite with real-time register and memory visualization.
- **[cvm](https://github.com/lvntky/cvm)** — A Java Virtual Machine implementation in C++.

## Research

Currently pursuing a master's degree in computer science, with research focused on async I/O and syscall runtimes on Linux. Planning to continue into a PhD.
